# Count (월 정산 및 대시보드 실행)

이 스킬이 실행되면 에이전트는 다음 단계를 순서대로 수행해야 합니다:

## Step 1: 원금 수정 여부 묻기
사용자에게 채팅으로 다음 질문을 던집니다.
"원금 수정이 필요하신가요? (Y/N)"

## Step 2: 원금 업데이트 스크립트 실행
사용자가 'Y'라고 대답하면, 터미널에서 아래 명령을 실행합니다.
명령어: `python scripts/update_principal.py`
*(주의: 이 스크립트는 대화형 입력이 필요할 수 있으므로, 사용자가 터미널에서 직접 실행하도록 안내하거나 에이전트가 백그라운드 태스크로 입력을 중계해 주어야 합니다.)*
사용자가 'N'이라고 대답하면 이 단계를 건너뜁니다.

## Step 3: 월 정산 스크립트 실행
Step 2가 완료되었거나 건너뛴 후, 다음 명령을 실행하여 월 정산을 수행합니다.
명령어: `python scripts/monthly_settlement.py`

## Step 4: 로컬 대시보드 실행
월 정산이 완료되면, 대시보드를 로컬에서 확인하기 위해 개발 서버를 실행합니다.
명령어: `npm run dev`
실행 후 사용자에게 "대시보드가 로컬 서버에서 실행되었습니다. 브라우저에서 확인해 주세요!"라고 안내합니다.
