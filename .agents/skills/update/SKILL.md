# Update (보유 주수 업데이트 스킬)

이 스킬이 실행되면 에이전트는 다음 단계를 순서대로 수행해야 합니다:

## Step 1: 대상 계좌 파악 및 선택
1. `src/data/portfolio.csv` 파일을 읽습니다.
2. `자산구분` 컬럼이 `보유종목_`으로 시작하는 행들을 찾아, 뒤에 붙은 계좌명(예: `ISA_정은`, `연금저축` 등)의 고유 목록을 추출합니다.
3. `ask_question` 툴을 사용하여 사용자에게 "어떤 계좌의 주수를 수정하시겠습니까?"라고 질문하고, 추출한 계좌명들을 선택지(options)로 제공합니다.

## Step 2: 해당 계좌의 포트폴리오 제시 및 입력 요청
1. 사용자가 계좌를 선택하면, 다시 `portfolio.csv`를 참조하여 해당 계좌에 속한 종목명(`상품명`)과 현재 `수량`을 파악합니다.
2. 파악된 포트폴리오 목록을 채팅창에 깔끔한 텍스트로 보여줍니다. (예: `1. KODEX 미국S&P500 (현재: 10주)`)
3. 사용자에게 "새로운 주수를 종목 순서대로 숫자만 입력하시거나, 변경할 종목의 이름과 숫자를 적어주세요. (예: 15, 20, 0 / 변경 없는 종목은 그대로 입력)"라고 안내하며 채팅 입력을 기다립니다.

## Step 3: CSV 업데이트
1. 사용자가 숫자를 입력하면, 사용자의 의도에 맞게 매핑하여 해당 종목들의 수량을 갱신합니다.
2. 임시 Python 스크립트 작성(`run_command` 이용) 혹은 CSV 파싱을 통해 `src/data/portfolio.csv` 파일의 해당 종목 `수량` 컬럼을 사용자가 입력한 숫자로 변경합니다. (0주 포함, 소수점도 가능)

## Step 4: 가격 갱신 및 Git 자동화
1. CSV 업데이트가 완료되면 터미널에서 다음 명령을 순서대로 실행합니다:
   - `python scripts/update_prices.py` (변경된 주수를 바탕으로 평가금액 재계산)
   - `git add src/data/portfolio.csv`
   - `git commit -m "chore(data): update portfolio shares via agent"`
   - `git push`
2. 모든 동작이 성공적으로 완료되면 사용자에게 "주수 업데이트와 평가금액 재계산, 그리고 Git 반영이 모두 완료되었습니다!"라고 안내하며 마무리합니다.
