# Windmill (풍차 1~12 평가금액 업데이트 스킬)

이 스킬이 실행되면 에이전트는 다음 단계를 순서대로 수행해야 합니다:

## Step 1: 풍차 계좌 현황 파악 및 제시
1. `src/data/portfolio.csv` 파일을 읽습니다.
2. `상품명`이 `풍차1`부터 `풍차12`까지인 행들을 찾아 각각의 **투자원금**, **현재 평가금액**, **수익률**을 파악합니다.
3. 파악된 12개 풍차 계좌 목록을 채팅창에 깔끔한 표 또는 리스트 형태로 보여줍니다.
   (예: `1. 풍차1: 원금 4,000,000원 | 평가금 6,142,611원 | 수익률 53.57%`)

## Step 2: 사용자 입력 요청
1. 사용자에게 새로운 평가금액 입력을 요청합니다:
   - "풍차 1번부터 12번까지 새로운 평가금액을 순서대로 입력하시거나(공백/쉼표 구분), 변경할 특정 풍차 번호와 금액을 적어주세요. (예: `풍차1 6200000`, 또는 `6150000, 5800000, ...` / 변경 없는 계좌는 기존 유지)"
2. 사용자의 채팅 입력을 기다립니다.

## Step 3: CSV 업데이트 및 수익률 재계산
1. 사용자가 입력한 금액에 맞게 각 풍차 계좌의 `평가금액` 컬럼을 갱신합니다.
2. 각 계좌의 새로운 수익률을 계산합니다:
   $$\text{수익률} = \frac{\text{새 평가금액} - \text{투자원금}}{\text{투자원금}} \times 100$$
   (소수점 둘째자리까지 표기, 예: `54.21%`)
3. `src/data/portfolio.csv` 파일의 `평가금액`과 `수익률` 컬럼을 갱신하여 저장합니다.
   *(터미널에서 `python scripts/update_windmill.py`를 활용하거나 직접 CSV를 파싱/수정할 수 있습니다.)*

## Step 4: Git 자동화 및 완료 안내
1. CSV 업데이트가 완료되면 터미널에서 다음 명령을 순서대로 실행합니다:
   - `git add src/data/portfolio.csv`
   - `git commit -m "chore(data): update windmill valuations via agent"`
   - `git push`
2. 모든 작업이 완료되면 변경된 내역(계좌명, 이전 평가금 → 변경 평가금, 수익률)을 정리하여 사용자에게 완료 보고를 합니다.
